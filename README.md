# Megatron 3000

Megatron 3000 es un sistema de gestión de bases de datos simple que permite realizar operaciones básicas sobre datos almacenados en archivos. Su objetivo es implementar funcionalidades esenciales para la manipulación y consulta de datos, siguiendo un enfoque relacional, compatible con SQL. El sistema se diseñó para explorar conceptos clave de bases de datos, incluyendo la lectura de datos, selección de columnas, condiciones con WHERE, uniones de tablas, y actualizaciones.

## Funcionalidades implementadas:

### 1. Lectura de datos: 
   - Lectura del esquema (Scheme) para entender la estructura de las tablas.
   - Lectura de instancias de datos desde archivos.

### 2. Selección de tablas:
   - Selección de todas las columnas con SELECT *.
   - Selección de columnas específicas.

### 3. Consulta con WHERE:
   - Aplicación de filtros a las consultas mediante la cláusula WHERE.

### 4. Unión de tablas:
   - Ejecución de consultas que requieren la unión de dos o más tablas.

### 5. Selección de unión de tablas:
   - Selección de resultados tras la unión de tablas con condiciones.

### 6. Actualización de valores:
   - Actualización de valores específicos en las tablas existentes.

### 7. Guardar una selección:
   - Posibilidad de guardar el resultado de una consulta en un archivo.
